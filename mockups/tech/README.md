# Универсальный UI блога — tech

Самостоятельное направление для `mockups/tech`: техническое сообщество, тёплая мастерская, лента в духе Хабра. React 19 + TypeScript + Vite, Lucide, безопасный Markdown с GFM. Ant Design не используется: компактные компоненты позволяют точнее соответствовать референсам.

## Память для агента

Для продолжения работы в новом чате начните с [AGENTS.md](AGENTS.md) и
[MEMORY.md](MEMORY.md). История задач — [memory/task-log.md](memory/task-log.md).
Каждый агент обязан обновлять память и дописывать журнал после каждой задачи.

## Запуск

Из корня репозитория:

```powershell
cd mockups/tech
npm ci
npm run dev
```

Локальный адрес: http://127.0.0.1:5174/ (отдельный порт от `press`).

```powershell
npm test
npm run build
npm run preview -- --port 5174
```

У статического хостинга должен быть SPA fallback на `index.html`.

## Как смотреть

- `/` — лента с крупными превью, сортировкой, фильтрами, подгрузкой и правой колонкой.
- `/prototype` — карта всех экранов; выбор ссылки сразу задаёт нужную тестовую роль и состояние.
- Кнопка «Прототип» снизу слева — роли Гость / Reader / Author / Moderator / Admin и ошибки/загрузка/пустые состояния. Это инструмент демонстрации, не управление ролями сервиса.
- `/prototype/responsive` — настоящий iframe шириной 390 или 768 px.
- Любой корректный email и непустой выдуманный пароль входят как Reader. Регистрация не выдаёт роль Author. Для редактора используйте тестовую роль через карту экранов.
- Для действительных почтовых ссылок на карте используется `?demo=valid`; это только явный режим демонстрации. Без него показана недействительная ссылка.

## Темы до деплоя

Скопируйте `.env.example` в `.env.local`, выберите `VITE_THEME` и перезапустите dev-сервер либо пересоберите:

```powershell
$env:VITE_THEME = 'blueprint'
npm run build
```

- `workshop`: лён, хвоя, янтарная мастерская; радио в hero.
- `blueprint`: бумага, индиго, инженерный чертёж; плата в hero, дека на входе.
- `midnight`: графит, медь, ночная смена; дека в hero, плата на входе.

Палитры: `src/themes/index.ts`. Бренд, меню, тексты и изображения: `src/brands/configs.ts`. Содержимое статей и их фото связаны по смыслу: смена бренда не подменяет радио фотографией усилителя. Runtime-переключателя нет. Незнакомая тема останавливает сборку.

## Граница прототипа

Все операции имитируются в памяти React с короткой задержкой. Backend, BFF и Identity не вызываются; письма не отправляются, реальные токены не создаются. Изменения сбрасываются после обновления. Закладки и поиск — UX-расширения локального прототипа; соответствующие backend endpoints отсутствуют в MVP.

Identity отвечает за имя, неизменяемый email, пароль и сеансы. Локальные роли блога назначает оператор; формы изменения ролей отсутствуют. В production браузер должен общаться с same-origin BFF, а токены должны оставаться на сервере. Макет этого соединения не реализует.

Часть внутренних mock-правил и базовых компонентов переиспользована из `press`. Лента, бренд, визуальная система, главная, статья, навигация, темы и материалы `tech` спроектированы отдельно. Папка `press` не изменялась.

## Generic-вариант

`npm run dev:generic` — тот же интерфейс на порту 5175 в нейтральной стилистике Ant Design.
`npm run build:generic` — отдельная статическая сборка в `dist-generic/`.
Выбор также доступен через `VITE_THEME=generic`. Бренд, палитра и содержимое вынесены в конфигурацию; описание — `docs/customization.md`.
