# Проверка прототипа

27 октября 2026. Все результаты относятся к локальному UI и тестовым данным.

## Автоматические проверки

- TypeScript strict (`tsc -b`) — проходит.
- Production build `workshop` — проходит.
- Production build `generic` — проходит, отдельный `dist-generic`.
- Дополнительные сборки `blueprint` и `midnight` — проходят.
- `npm test`: 6 из 6 проходят. Проверяются ANY категорий / ALL тегов, сохранение предков скрытых/удалённых комментариев с видимыми ответами, правила Unicode/NFKC пароля, фиксированное окно 24 ч для просмотров, запрет устаревшей версии, slug и Unicode scalar length.
- При первой попытке sandbox запрещал дочерние процессы Node/Vite (EPERM); те же команды успешно исполнены с разрешением локального запуска процессов.

## Граница проверки

Реальные Blog API, BFF, Identity, SMTP, JWKS и отозванные JWT не проверялись — интеграция намеренно заменена mock-адаптером. Текущий пароль и принадлежность email реальному человеку не проверяются. Состояние деактивации, завершение сеансов, логин и смена пароля моделируются только в памяти вкладки. Production-проверки screen reader, доступности и контраста всех цветовых состояний ещё нужны при внедрении.

Дополнительно проверено: generic-модератор открывает список комментариев и диалог восстановления скрытого комментария. Операция возвращает сообщение в видимое состояние. Действия переписывания и удаления чужого текста недоступны роли Moderator.
