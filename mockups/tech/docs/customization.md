# Варианты бренда и темы

Интерфейс универсален: РетроТех Лаб — один из пакетов конфигурации, а не имя движка и не условие работы страниц.

## Готовые варианты

| Выбор перед сборкой | Бренд | Визуальное направление |
| --- | --- | --- |
| `VITE_THEME=workshop` | retrotech | Лён, хвоя, фотография мастерской |
| `VITE_THEME=blueprint` | retrotech | Светлая бумага, индиго, плата |
| `VITE_THEME=midnight` | retrotech | Графит, медь, тёмные поверхности |
| `VITE_THEME=generic` | generic | Нейтральная стилистика Ant Design: синий #1677ff, белые карточки, системный sans-serif |

Для generic есть отдельные команды:

```powershell
npm run dev:generic
npm run build:generic
```

Preview: порт 5175. Сборка: `dist-generic/`. Эти команды читают `.env.generic`. Настоящего runtime-переключателя в продукте нет.

Generic выполнена в стиле Ant Design на общих React-компонентах проекта. Пакет `antd` не установлен; не заявляем, что это библиотечные компоненты Ant Design. Визуальные ориентиры: [design tokens](https://ant.design/docs/react/customize-theme/) и [layout](https://ant.design/components/layout/). Общие формы/диалоги/состояния и сценарии Identity одинаковы для обоих вариантов.

`VITE_BRAND=retrotech|generic` можно задать независимо, чтобы явно выбрать содержимое бренда. Визуальный профиль задаёт поле `presentation` (workshop или ant); цвета задаёт тема. Готовые сочетания приведены выше, остальные сочетания требуют визуальной проверки. Если бренд не задан, тема generic выбирает generic, остальные — retrotech. Если задан только generic-бренд, по умолчанию используется generic-палитра.

## Где менять кастомизацию

- `src/brands/configs.ts`: визуальный профиль presentation, название, wordmark и знак, слоган, меню, тексты главной/статьи/входа/о проекте, sidebar, авторы, категории, теги, изображения.
- `src/brands/content.ts`: тематические демопубликации и комментарии. Generic получает собственные нейтральные данные.
- `src/brands/index.ts`: статический выбор пакета.
- `src/themes/index.ts`: основные палитры, дополнительные `tones` и статическое применение CSS variables.
- `src/themes/tones.ts`, `src/themes/tones.css`: стабильный цвет тега по slug, соответствие цветов статусам и общие состояния цветных элементов.
- `src/tech.css`: базовое визуальное направление и увеличенная типографика.
- `src/generic.css`: презентационный слой generic в стиле Ant Design.
- `vite.config.ts`: проверка конфигурации; title, description и favicon формируются для выбранного бренда уже в HTML сборки.

Страницы, маршруты, редактор, правила доступа, модерация, комментарии и Identity не дублируются для брендов. Набор публикаций, названия категорий, URL тематических страниц и стартовая статья карты сценариев следуют выбранному пакету.

## Дополнительные цвета

У каждой темы собственные `tones.blue`, `orange`, `red`, `green`, `purple` с полями `ink`, `bg`, `border`. При запуске они превращаются в `--tone-blue-ink`, `--tone-blue-bg`, `--tone-blue-border` и аналогичные переменные остальных цветов. Сочетания подобраны под температуру и светлоту основной темы.

Для тегов используйте `data-tone={tagTone(tag.slug)}`: один slug всегда получает один цвет. Компонент `Badge` принимает как цвет (`tone="purple"`), так и статус (`tone="success"`). `Alert` и уведомления используют семантические соответствия из `statusTones`. Красная `colors["danger-fill"]` предназначена для заливки опасных кнопок; текст ошибки получает читаемый `--tone-red-ink`, в том числе в midnight. Общие цветовые правила находятся в `tones.css`, размеры и форма — в presentation-слоях.

В generic нет ретрофотографий в карточках, serif-типографики и текстов РетроТех. В качестве примера используется условный бренд «Сообщество». Замените его в пакете своей конфигурацией.

## Изменения после визуального ревью

Текст статьи 16 px, UI 14 px, второстепенные подписи преимущественно 12–13 px. Небольшие декоративные подписи и слоган логотипа могут быть меньше; функциональные поля и действия остаются читаемыми. Шапка retrotech: знак микросхемы, wordmark со слоганом, активный раздел со светлой заливкой, поиск, колокольчик с локальной демонстрацией ответов, круглый профиль.
