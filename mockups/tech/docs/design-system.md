# UI architecture и дизайн-система

## Направление

«Живая инженерная мастерская». Структура Хабра: последовательная лента, контекстные метаданные, читаемая статья, дерево обсуждений, правая колонка. Бренд РетроТех Лаб из референсов: хвоя, лён, медь, старая электроника, простой знак микросхемы. Вместо журнальных плиток — полноценные карточки материалов.

## Сетка и типографика

- Максимальная ширина 1216 px (1280 на больших экранах); фон страницы отделяет белые карточки.
- Desktop: основная колонка + sidebar 292 px, gap 28 px. Sidebar исчезает до 760 px.
- Над каждой лентой — одна компактная строка: «Свежее» / «Популярное» слева,
  «Фильтры» справа. Дублирующий заголовок ленты со счётчиком и подпись
  «Опыт, которым делятся» удалены во всех вариантах Journal (главная, категория,
  тег, автор, поиск, закладки) и обеих темах. Контекстные H1 страниц сохранены;
  секция ленты имеет доступное имя через aria-label. Фильтры раскрываются ниже
  строки категорий. Старые стили удалённого блока убраны.
- Карточка: автор/дата/закладка → заголовок → категория/время/теги → обложка → описание и три первых текстовых абзаца статьи → «Читать далее» и счётчики. Превью выводит полные абзацы без обрезки по строкам, шрифт 16 px, интерлиньяж 1.8. Общий компонент работает в обеих темах; заголовки, таблицы, кодовые блоки и дополнительные изображения остаются в статье.
- H1/названия разделов: Georgia с кириллицей. Интерфейс и текст статьи: Segoe UI. Markdown editor: Cascadia Code / Consolas. Внешние web fonts не загружаются.
- Карточки 8–10 px, поля и кнопки 6 px. Тонкие границы, тени с низкой интенсивностью.
- Категории РетроТех — плашки 34 px высотой со скруглением 11 px и текстом
  14 px. Нейтральный фон без рамок, активная категория выделена акцентной
  заливкой без внутреннего контура. Gap 10 px; на телефоне строка прокручивается
  горизонтально. Nav имеет доступное имя, выбранный пункт — aria-current;
  контур фокуса появляется при работе с клавиатурой. Generic сохраняет Ant-профиль.
- Отступы строятся вокруг 4/8 px, внутренний padding 16–26 px.

## Компоненты

Иконки публикаций собраны в `components/PostIcon.tsx`: сердце, просмотры,
комментарии, закладка и ссылка используют одну сетку 24 × 24, линию 1,8 и
скруглённые окончания. Глаз выше стандартного Lucide Eye, чтобы видимая высота
сочеталась с сердцем и комментарием. Размер контейнера — 22 px, до 450 px —
20 px; в блоке «Сейчас читают» — 15 px. В ленте и панели статьи порядок один:
просмотры → комментарии → лайки. Общие стили `components/post-actions.css`
подключены после presentation-слоёв.

Активный лайк workshop — тёплое градиентное сердце со светлой обводкой 1,25,
бликом и мягким ореолом. Цвета взяты пипеткой из пользовательского референса:
`#fc9450` → `#fa672f` → `#f6482d`, свечение `#fc8337`.
Источник сохранён в `references/post-actions-glow-reference.png`.
Generic использует синий, blueprint — приглушённый синий, midnight — медный.
Токены `like-*` находятся в `themes/index.ts`; страницы не задают hex-цвета.
Нажатие мягко сжимает сердце, включение даёт один плавный импульс 580 ms,
ореол появляется/исчезает за 560 ms. `prefers-reduced-motion` убирает движение.
Запрос лайка блокирует повторный клик без мигания и изменения ширины кнопки;
кнопки в начале/конце статьи и карточка используют общее состояние реакции.

`components/ui.tsx`: Button со busy/disabled, Badge, Alert, Field, Modal с focus trap и восстановлением фокуса, Skeleton, EmptyState, Guard, Toasts.

`components/Layout.tsx`: логотип, compact header, поиск Ctrl/Cmd+K, mobile nav, меню аккаунта, рабочая навигация, footer, отделённый demo controller.

`pages/Journal.tsx`: общая карточка, лента, направления, автор, поиск, закладки, правая колонка. `pages/Article.tsx`: безопасный Markdown, статья, оглавление, обсуждение. `Workspace`, `Moderation`, `Identity`: отдельные рабочие сценарии. `Prototype`: карта состояний.

`mock/data.ts`: типы и согласованные fixtures; `mock/store.tsx`: локальный адаптер и ограничения; `mock/rules.ts`: чистые контрактные правила. Состояние хранится в памяти без токенов и сетевых запросов.

## Темы

Четыре статически выбираемых пакета: workshop, blueprint, midnight, generic. CSS variables содержат фон, поверхность, основной и вторичный текст, границу, акцент, мягкую заливку, hero и тёплый акцент. Каждая тема также задаёт пять дополнительных цветов: синий, оранжевый, красный, зелёный и фиолетовый. Для каждого определены текст, заливка и граница; для опасных действий — отдельная красная заливка с белым текстом. Workshop использует припылённые природные оттенки, blueprint — прохладные бумажные, midnight — тёмные поверхности со светлыми акцентами, generic — чистые пастельные оттенки. Пакет также содержит hero/auth, alt и набор содержательных обложек. Цветовая схема `color-scheme` устанавливается вместе с темой. Runtime-переключения нет.

`themes/tones.ts` выбирает цвет тега по slug: он одинаков в карточке, sidebar, статье, каталоге тем и фильтрах ленты/редактора независимо от порядка элементов. Общие стили `themes/tones.css` подключаются после presentation-слоёв. Hover усиливает заливку и границу; выбранный фильтр дополнительно имеет двойную рамку, галочку и `aria-pressed`. Цвет не заменяет подпись или состояние выбора.

Badge поддерживает именованные цвета и статусы; Alert сопоставляет info → синий, warning → оранжевый, error → красный, success → зелёный. Toast, ошибки полей и опасные кнопки используют ту же палитру темы. Новые пары текста/заливки проверены расчётом контраста: минимум 4,64:1 в обычном состоянии и hover. Это проверка новых цветовых пар, а не полный аудит доступности интерфейса.

Новый бренд добавляется в `themes/index.ts` и список допустимых тем `vite.config.ts`; иллюстрации сохраняются в public/images. Код страниц не зависит от конкретных hex-цветов бренда; декоративная карточка мастерской имеет отдельные адаптации для тем.

## Адаптивность и доступность

До 760 px — одна колонка, мобильная навигация, горизонтальная строка тем и рабочего меню; обложки ниже, боковые подсказки убираются. До 450 px — компактные счётчики, перенос byline, редактор с настройками под текстом. Preview `/prototype/responsive` создаёт реальный 390/768 px iframe.

Клавиатурный фокус видим; формы имеют label и ошибки, кнопки-иконки имеют доступные имена, диалог закрывается Escape и удерживает Tab, уведомления используют aria-live. Нет обязательного hover для действий. `prefers-reduced-motion` отключает анимации. Таблицы и code blocks прокручиваются внутри статьи. Для внедрения нужна дальнейшая проверка screen reader и контраста всех состояний реальными инструментами.

## Дополнение после ревью

Типографика увеличена: статья 16 px, UI 14 px, метаданные 12–13 px. Шапка retrotech приближена к референсу пользователя. Добавлена четвёртая нейтральная тема generic в стиле Ant Design с отдельными текстами и демоданными. Общие страницы и сценарии не дублируются. Полная схема выбора бренда, темы и содержимого: `customization.md`.

Колокольчик в шапке показывает локальную подборку тестовых ответов на комментарии. Это UX-демонстрация, а не интеграция notification API.
