# Память агента — tech UI

Актуализировано: 2026-10-27 (Asia/Omsk).
Перед работой прочитай `AGENTS.md`; после каждой задачи обнови эту память и
добавь запись в `memory/task-log.md`.

## Назначение и запрос пользователя

Локальный React UI-прототип универсального блога в `mockups/tech`.
Нужно проектировать UI/UX всех основных сценариев по спецификации: лента,
статьи, обсуждение, работа автора, модерация и весь цикл аккаунта Identity.
Операции выполняются на тестовых данных, обращения к сервисам заменены заглушками.

Сохранённые предпочтения пользователя:

- Направление `mockups/press` не понравилось. У `tech` собственный визуальный
  дизайн; часть mock-правил и базовых компонентов была переиспользована.
- Лента должна напоминать Хабр: последовательные полноценные карточки с длинным
  анонсом, метаданными, обложкой, чтением и счётчиками.
- Мелкие шрифты не устраивают: текст статьи и длинного превью — 16 px,
  функциональный UI преимущественно 14 px, метаданные 12–13 px.
- Header РетроТех Лаб должен быть очень близок к пользовательскому референсу:
  отдельный знак микросхемы, wordmark со слоганом, светлая заливка активного
  раздела, поиск, колокольчик и круглый профиль.
- РетроТех Лаб — только один вариант кастомизации generic-интерфейса.
  Не зашивай его название, тематику или фотографии в общую логику страниц.
- Есть нейтральная generic-тема в стиле Ant Design: синий акцент, светлые
  поверхности, sans-serif и отдельные нейтральные тексты/демоданные.
- Темы (цвета и картинки) выбираются статически до деплоя. Runtime-переключатель
  пользователь не запрашивал.
- Пользователь просит каждого агента сохранять контекст после каждой задачи.
- Для каждой темы нужны согласованные дополнительные цвета тегов и элементов
  управления: синий, оранжевый, красный, зелёный и фиолетовый.
- Дублирующие заголовки лент со счётчиками и декоративная подпись «Опыт, которым
  делятся» избыточны и создают пустоту. Убраны во всех страницах Journal и обеих
  темах. «Фильтры» должны быть на одной строке справа от сортировки.
- Для hero РетроТех пользователь прислал отдельный референс мастерской:
  приёмник справа, осциллограф, лампа, деревянный стол и спокойная светлая зона
  слева под HTML-текст. По нему сгенерирован новый панорамный баннер.
- Категории над лентой РетроТех — мягкие плашки по референсу. Пользователь
  уточнил: высота 44 px слишком большая, обводки не нужны. Итог: 34 px,
  скругление 11 px, нейтральная заливка; активная категория выделяется цветом.
- Иконки публикации должны иметь единый стиль и гармоничную видимую высоту.
  Порядок слева направо: просмотры → комментарии → лайки. В workshop активное
  сердце имеет ламповый красно-оранжевый эффект по референсу; цвета взяты из
  изображения, белый край по уточнению пользователя уменьшен до 1,25.
  В остальных палитрах тоже нужна подсветка и плавная анимация нажатия.
- Подпись после «На одной волне» должна печататься и стираться. Нужно 50
  вариантов в случайном порядке: все фразы без повторов за круг, затем новое
  перемешивание без одинаковых соседних фраз на границе кругов.

## Текущее состояние

Реализован самостоятельный React 19 / TypeScript / Vite-прототип. Используются
React Router, Lucide, React Markdown и GFM. Пакет `antd` не установлен:
generic воспроизводит визуальное направление Ant Design общими компонентами.

Hero retrotech/workshop: `public/images/retrotech-hero-v2.png`, встроенный image_gen,
2172 × 724. Выбор задан в `brand.images.workshop[0]`; этот hero также используется
на странице «О проекте». Исходный пользовательский референс сохранён в
`references/retrotech-hero-reference.png`, полный промпт — `public/images/sources.md`.
Старое `workshop.png` остаётся иллюстрацией статей и входа. Фото hero других палитр
и generic не заменялись. Тексты и кнопки сайта не запечены в новый баннер.
В v2 исправлены две рукописные «т» в «Это история.» — три штриха вместо двух.
V1 сохранена как `public/images/retrotech-hero.png`, образец правильных букв —
`references/retrotech-lettering-corrected.png`. При правке мелкого текста на
большом баннере помогла генерация крупного плана и перенос его на полный кадр.

Есть лента, сортировка и фильтры, поиск, закладки, авторы, категории и теги,
статья с оглавлением, реакции и дерево комментариев, рабочая область автора,
редактор с предпросмотром, публикация/снятие/удаление, модерация, таксономия,
профиль и сценарии Identity. Полный каталог — `docs/scenarios.md` и `/prototype`.

Полоса сообщества на главной retrotech: `brands/retrotechPhrases.ts` содержит
50 уникальных продолжений «На одной волне». Общий `TypewriterText` перемешивает
их алгоритмом Fisher–Yates, выдаёт все до следующего перемешивания и исключает
повтор на стыке кругов. Первый вариант тоже случаен. Печать — 65 ms/символ,
пауза чтения — 2400 ms, стирание — 30 ms/символ, промежуток — 450 ms.
Мигающий курсор, невидимая сетка фраз резервирует точную максимальную ширину.
До 1150 px подпись переходит под заголовок, до 760 px полоса переносит блоки.
Вне экрана и в скрытой вкладке JS-цикл приостанавливается; reduced-motion
оставляет исходную фразу статичной без курсора. Скринридер получает одну полную
статичную подпись. Тексты заданы в brand.feed.stripPhrases, generic передаёт
пустой набор и сохраняет прежний вариант полосы.

Над лентой теперь только `feed-toolbar`: «Свежее» / «Популярное» слева и
«Фильтры» справа, затем категории. Большой повторный заголовок со счётчиком
и подпись удалены из общего Journal: главная, категория, тег, автор, поиск,
закладки. Контекстные H1 страниц сохранены; секция имеет aria-label. Старые
стили `tech-feed-heading` и подписи убраны; состояния сортировки обозначены
aria-pressed. Панель фильтров раскрывается ниже категорий.

Категории в `tech-topic-strip` оформлены как плашки: 34 px высотой, 14 px текст,
11 px скругление, gap 10 px. У неактивных нейтральная заливка, у активной —
акцент темы; рамок и внутренних контуров нет. На узком экране строка прокручивается
горизонтально без сжатия элементов. Разметка — nav с доступным именем и
aria-current; отдельный контур появляется только при клавиатурном фокусе.
«Все темы» сокращено до «Все». Generic сохраняет отдельный Ant-профиль.

Все четыре темы имеют `tones` (blue/orange/red/green/purple: ink/bg/border).
Workshop — припылённые природные цвета, blueprint — прохладные бумажные,
midnight — тёмные заливки со светлым текстом, generic — чистые пастельные.
`themes/tones.ts` стабильно назначает цвет тега по slug; он сохраняется в ленте,
sidebar, статье, каталоге тем, фильтрах и редакторе. Общий `tones.css` подключён
последним. Выбранные теги-фильтры имеют усиленную рамку, галочку и aria-pressed.
Badge/Alert/Toast используют ту же палитру: info=blue, warning=orange,
error=red, success=green. `--danger` следует red.ink, опасные кнопки имеют
отдельный `danger-fill` с белым текстом; старые локальные цвета статусов убраны.

`PostPreview` выводит описание и до трёх первых текстовых абзацев Markdown.
Абзацы полные, без line-clamp; заголовки, таблицы, списки, code blocks,
цитаты и дополнительные картинки в текстовый анонс не включаются. Сохраняется
безопасная inline-разметка. Внизу — «Читать далее». Компактный вариант карточки
может показывать только описание. Демотексты дополнены под заголовки.

`components/PostIcon.tsx` — общий SVG-набор действий публикации: heart, views,
comments, bookmark, link. Одинаковые сетка/толщина линии/скругления, оптически
увеличенная высота глаза. Контейнеры 22 px на desktop, 20 px до 450 px, 15 px
в sidebar. В ленте и статье порядок views → comments → heart; лайк одинаковый
в панели статьи и её нижней кнопке. `components/post-actions.css` подключён
последним и содержит свет, hover/focus и анимацию. `themes/index.ts` задаёт
`like-*`: workshop #fc9450/#fa672f/#f6482d, generic/blueprint синий, midnight
медный. Свечение статичное после импульса 580 ms, включение/выключение ореола
560 ms; reduced-motion отключает движение. Светлый край активного сердца 1,25
при обычном контуре 1,8. Референс — `references/post-actions-glow-reference.png`.
На время запроса повторный лайк блокируется без изменения ширины кнопки.

Вся работа с данными — в памяти вкладки, после перезагрузки состояние сбрасывается.
Реальные Blog API, BFF, Identity и SMTP не подключены. Закладки, локальный поиск
и подборка ответов под колокольчиком — UX-демонстрации, не готовые backend endpoints.

Identity: вход, регистрация, подтверждение и повторное письмо, восстановление/
сброс пароля, приглашение, истёкший сеанс, профиль, смена пароля, сеансы и
деактивация. Ссылки `?demo=valid` — явный режим демонстрации. Реальные токены,
письма и проверка владения email отсутствуют. Не придумывай social login/MFA и
другие возможности сверх контракта. Детали — `docs/scenarios.md` и Identity spec.

## Как продолжить в новом чате

Рабочая папка: `D:\Space\Personal\blog\mockups\tech`.

```powershell
cd D:\Space\Personal\blog\mockups\tech
npm run dev             # workshop/retrotech: http://127.0.0.1:5174/
npm run dev:generic     # generic: http://127.0.0.1:5175/
npm run build           # TypeScript + dist/
npm run build:generic   # TypeScript + dist-generic/
npm test                # 6 существующих контрактных тестов
```

Не считай dev-процессы и браузерные вкладки сохранёнными между чатами. Сначала
проверь доступность нужного адреса; не запускай второй сервер на занятом порту.
Зависимости описаны в `package.json` и lock-файле; установка при необходимости —
`npm ci`. `node_modules`, основные `dist`/`dist-generic` и локальные env
игнорируются Git. `dist-blueprint`/`dist-midnight` сейчас отслеживаются:
для следующих проверок предпочитай временный outDir вне этих каталогов.
После текущих проверок их исходные файлы восстановлены, результаты UI сохранены
в `docs/previews/`.

`/prototype` — карта экранов и состояний, `/prototype/responsive` — реальные
iframe 390/768 px. Кнопка «Прототип» снизу слева выбирает тестовую роль и ошибки.
Роли Guest / Reader / Author / Moderator / Admin задаются локально для ревью.
Это не административное назначение ролей в реальном сервисе.
